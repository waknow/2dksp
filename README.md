# 2DKSP — 2D 轨道模拟器

基于 TypeScript 和 Vite 构建的二维轨道力学模拟器。发射一个抛射体绕中心大质量天体运行，体验不同积分器、物理步长和初始条件对轨道的影响。

## 功能特性

- **交互控制** — 通过滑块实时调整初始速度、行星质量、物理步长和预测时间
- **多种积分器** — 对比显式欧拉、半隐式欧拉、速度 Verlet 和 Leapfrog 四种积分方法
- **实时可视化** — 同时显示预测轨迹和实际飞行路径
- **键盘快捷键** — `空格` 发射，`R` 重置，`1`–`4` 切换时间倍率，滚轮缩放

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/)（建议 v18 或更高版本）

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

在终端中打开显示的 URL（默认为 `http://localhost:5173`）。

### 构建生产版本

```bash
npm run build
```

构建产物输出到 `dist/` 目录。

### 预览生产版本

```bash
npm run preview
```

## 操作说明

| 按键 / 控件           | 功能                           |
|------------------------|--------------------------------|
| `空格`                 | 发射抛射体                     |
| `R`                    | 重置模拟                       |
| `1` / `2` / `3` / `4` | 时间倍率（1×、2×、5×、10×）   |
| 鼠标滚轮               | 缩放视图                       |
| 速度滑块               | 调整水平初始速度               |
| 质量滑块               | 调整中心行星质量               |
| 积分器下拉框           | 切换数值积分方法               |
| 物理步长滑块           | 调整每秒模拟步数               |
| 预测时间滑块           | 设置预测轨迹时长（秒）         |
